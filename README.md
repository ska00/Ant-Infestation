# Ant Infestation: Ludum Dare 56

Click [here](https://ska00.github.io/Ant-Infestation/) to play.

Fight against a number of ants that are trying to infest your home!

Controls:
- Left-click to throw rocks at them.
- Use Q to drop sugar which attracts a random number of ants around it (does not affect special ants)
- Use W to drop poison bombs on ants slowing them down
- Use E to step on ants. Does a lot of damage
